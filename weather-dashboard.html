About This Dashboard

This weather dashboard uses the free Open-Meteo API, which provides accurate weather data without requiring an API key. Data is updated in real-time with a 10-minute refresh interval.

Data Source

Powered by Open-Meteo - A free weather API for open-source projects and non-commercial use.

Get Started

Search for a location or use your current location to view detailed weather information including hourly and 7-day forecasts.
